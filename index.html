Why Visiq
なぜ、Visiqなのか。

高額なMAツールを導入しなくても、メール後のWeb行動を個人単位で計測できます。AWSで自前実装するより圧倒的に速く、安く。

💸
HubSpot・Marketoは高すぎる
「SES・SendGridで配信は十分。でもWeb行動だけライトに計測したい」——その中間層のニーズに応えます。月¥1,980から。
🛠
AWS自前実装は面倒すぎる
Lambda + DynamoDB + Athenaで自前構成を組む工数を、ゼロに。スニペット1行とURLパラメータだけで完結します。
🔒
1st Partyデータで安全
3rd Party Cookie規制に無関係。自社ドメイン内の行動を、メールIDと1対1で紐づける仕組みなのでプライバシーリスクが低い。
How it works
シンプルな仕組み。

既存の配信システムに数行追加するだけ。複雑なSDKや専用インフラは不要です。

01
メンバー登録 & トークン取得
メール送信前にVisiq APIを呼び、読者ごとの token_value を取得します。
02
URLにトークンを付与して配信
SES・SendGrid・める配くんのテンプレートに ?ma_token=xxx を仕込むだけ。
03
JSスニペットが自動でビーコン送信
サイトに埋め込んだ <script src="snippet.js"> が訪問・滞在・離脱を自動記録。
04
APIでデータを取得・AIへ渡す
「誰がどのページを何秒見たか」をAPIで取得。CRM・AIエージェント・Slackなどに自由に連携できます。

Use Cases
こんな使い方ができます。

配信ツールの種類を問わず、同じAPIで繋がります。

Amazon SES
SESユーザーに最も刺さる
SESはコスト最安だが「送った後の行動」が追えない。Visiqを組み合わせると、Lambda + DynamoDBを自前で構築する工数なしに、1to1トラッキングが完成します。
# TemplateDataにトークンを渡すだけ "visiq_token": get_visiq_token(user_email)
SendGrid
Dynamic Templateと組み合わせる
SendGridのDynamic Template変数に {{visiq_token}} を仕込むだけ。クリック計測の先、「サイトで何を何秒見たか」まで把握できます。
# personalizations内で渡す "dynamic_template_data": { "visiq_token": token_value }
める配くん
自社サービスとのシームレス連携
める配くんのリンクにトークンを付与するだけで、配信後の読者行動をVisiqが自動記録。既存ユーザーへのβ提供から需要を検証できます。
# リンク生成時にパラメータ付与 url = f"{base_url}?ma_token={token}"
AIエージェント
AIのデータソースとして使う
AIエージェントはVisiq APIを叩くだけで「読者Aは今、料金ページを5分見ている」というコンテキストを取得。自律的なフォローアクションを判断できます。
# AIがAPIを呼ぶだけ GET /api/members/{id}/summary → { total_page_views, last_seen_at }
